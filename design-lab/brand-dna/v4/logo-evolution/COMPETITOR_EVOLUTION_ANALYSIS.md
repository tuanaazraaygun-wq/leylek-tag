# Competitor Logo Evolution Analysis

**Phase:** P1 — Logo Evolution Analysis  
**Mode:** Read-only research

**Scope:** Logo tamamen değişmeden nasıl modernleşti? — LeylekTAG evrim dersleri

## 0. Executive summary

Büyük teknoloji ve mobility markaları logolarını **rebrand etmeden evrimleştirdi**: siluet korundu, detay azaltıldı, platform sistemleri (tier, adaptive, motion) eklendi. LeylekTAG için ders: **premium kuş + arc DNA'sını koru; üç paralel aileyi birleştir; küçük boyutu tier ile çöz**.

| Marka | Evrim stratejisi | LeylekTAG dersi |
|-------|------------------|-----------------|
| Apple | Siluet sabit; detay + renk sadeleşti | Gaga+arc siluet dokunulmaz |
| Google | Wordmark refine; renkler flat kaldı | "Leylek TAG" hiyerarşisi korunur |
| Uber | Pin sadeleşti; tek form global | Tutarlılık — ama pin generic, kuş korunur |
| Airbnb | Bélo evrimi; anlam korundu | Sembol anlamı > trend formu |
| Spotify | Daire + dalga; yeşil sabit | Accent renk genom kilidi |
| Discord | Mascot → flat icon; mor sabit | LeylekEye companion ayrı lane |
| Stripe | Wordmark precision | Geometric restraint |
| Notion | Minimal cube → daha minimal | Küçük boyut önce |
| Telegram | Kağıt uçak sadeleşti | Tanınır siluet korundu |
| WhatsApp | Telefon + balon sadeleşti | Tek metafor global |
| Bolt | Yeşil + B; flat geometry | Tek accent gücü |

## 1. Apple

### Evrim özeti

| Dönem | Form | Değişim |
|-------|------|---------|
| 1976–1998 | Rainbow Apple | Renkli bantlar |
| 1998–2001 | Translucent / Aqua | Skeuomorphism |
| 2001–2007 | Chrome glass | 3D derinlik |
| 2007–2013 | Glossy | Highlight azaldı |
| 2013–günüm | Flat monochrome | **Siluet aynı** |

### Nasıl modernleşti?

1. **Siluet hiç değişmedi** — ısırık + yaprak formu 50 yıldır aynı.
2. **Malzeme evrimi** — skeuo → flat; okunurluk arttı.
3. **Renk çıkarıldı** — monochrome = timeless + küçük boyut.
4. **Adaptive** — iOS squircle, watch complication tier'ları.

### LeylekTAG dersi

- Premium kuş profili = Apple ısırığı gibi **dokunulmaz siluet**.
- 3D metal shader → flat/light emboss = Apple'ın gloss → flat geçişi.
- iOS/Android/watch için tier ladder zorunlu.

## 2. Google

### Evrim özeti

| Dönem | Form |
|-------|------|
| 1998–2010 | Serif "Google" + exclamation |
| 2010–2013 | Flat color wordmark |
| 2013–2015 | Sans refinement |
| 2015 | Product Sans + flat colors |
| 2025 | Material light/dark variants |

### Nasıl modernleşti?

1. **Wordmark aynı kelime** — tipografi refine, devrim yok.
2. **Renkler korundu** — flat + tutarlı palette.
3. **Responsive system** — G icon ayrı; wordmark ayrı.
4. **Küçük ekran önce** — icon-first dünya.

### LeylekTAG dersi

- "Leylek" + "TAG" = Google kelimesi gibi korunur.
- feature-graphic lockup refine edilir; kelimeler değişmez.
- Symbol (kuş) + wordmark ayrı katman — navbar M1 + text.

## 3. Uber

### Evrim özeti

| Dönem | Form |
|-------|------|
| 2010–2012 | "Uber" black text |
| 2012–2016 | U + wordmark |
| 2016–2018 | Bitstream wordmark |
| 2018–günüm | **Minimal pin** "U" inside circle |

### Nasıl modernleşti?

1. **Tek global icon** — her ülkede aynı pin.
2. **Detay silindi** — kelime → sembol.
3. **Siyah/beyaz restraint** — premium mobility.

### LeylekTAG dersi — al / alma

| Al | Alma |
|----|------|
| Platform tutarlılığı | Pin formu (generic) |
| Tek icon global | Uber pin kopyası |
| Minimal restraint | Kelimeyi tamamen silmek (LeylekTAG wordmark gerekli) |

**LeylekTAG farkı:** Uber pin = konum commodity. Leylek kuş = kültürel özgünlük — **kuş korunur, pin retire**.

## 4. Airbnb

### Evrim özeti

| Dönem | Form |
|-------|------|
| 2008–2014 | Bubble script "Airbnb" |
| 2014–günüm | **Bélo** — A + heart + location pin birleşimi |
| 2021+ | Bélo refine — stroke kalınlık, spacing |

### Nasıl modernleşti?

1. **Anlam korundu** — belonging + travel + people.
2. **Script → symbol** — ama sembol anlam taşıyor.
3. **2014 shock → 2021 refine** — ikinci evrim daha az sarsıcı.
4. **Custom type (Cereal)** — wordmark ayrı asset.

### LeylekTAG dersi

- İlk büyük değişim (2014 Airbnb) sarsıcıydı; **LeylekTAG evrim küçük adımlar** — DNA freeze kritik.
- Orbital arc = Bélo'nun birleşik sembolü gibi **anlamlı geometry**.
- Wordmark custom font opsiyonel — P1'de font devrimi yok.

## 5. Spotify

### Evrim özeti

| Dönem | Form |
|-------|------|
| 2008–2013 | Orange "Spotify" text |
| 2013–2015 | Green circle + sound waves |
| 2015–günüm | Flat green + refined waves |
| 2024+ | Dark/light adaptive green |

### Nasıl modernleşti?

1. **Yeşil = marka** — renk değişmedi, ton refine.
2. **Daire + dalga** — basit geometry küçük boyutta hayatta.
3. **Motion** — dalga animasyonu marka DNA.

### LeylekTAG dersi

- Cyan accent = Spotify yeşili gibi **genom kilidi** (`#00D4AA`).
- Arc sweep = sound wave gibi **motion-ready geometry**.
- Boot pulse arc üzerinde — Spotify dalga mantığı.

## 6. Discord

### Evrim özeti

| Dönem | Form |
|-------|------|
| 2015–2021 | "Clyde" mascot face — detaylı |
| 2021–günüm | **Blurple gamepad-like icon** — sadeleşmiş |

### Nasıl modernleşti?

1. **Mascot → icon** — detay kaybı ama renk + şekil recall yüksek.
2. **Blurple sabit** — mor genom.
3. **Adaptive** — sunucu icon vs app icon ayrımı.

### LeylekTAG dersi

- LeylekEye = Discord Clyde gibi **companion** — logo değil.
- Logo sadeleşirken Eye ayrı lane kalır; iris cyan hizalanır.
- Violet/AI moru Discord blurple değil — **LeylekTAG yasak**.

## 11. Bolt

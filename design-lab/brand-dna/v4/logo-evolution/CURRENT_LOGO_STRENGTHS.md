## Koruma ilkesi

Logo evrimi **marka değiştirmez**. Aşağıdaki güçler, evrim sonrası da tanınabilir kalmalıdır. F1 Meridian Wing analizi bu listeyi **geometry + restraint** ile taşımayı hedefler; metaforu değiştirmeyi değil.

---

## 1. Sembolik güç — Leylek metaforu

| Güç | Kanıt | Koruma notu |
|-----|-------|-------------|
| **Kültürel tanınırlık** | Leylek = göç, yol, mesafe, Türkiye coğrafyası | Rakiplerde (Uber, Bolt, BiTaksi) yok |
| **Premium kuş silueti** | `leylek-logo-premium.png` — profil leylek, tek ayak | Kullanıcı "kuş uygulaması" algısı oluşmuş |
| **Kanat çizgisi** | SVG pin içi kanat path; premium kuş kanat oyuk | F1 wing arc'ın doğrudan atası |
| **Orbital arc / halka** | Premium PNG alt sweep; wireframe icon oval | Lock ring, güven, kapanış metaforu |
| **Cyan accent nokta** | Pin merkez dot; wireframe icon teal dot; kuş gözü glow | Meridian accent (`#00D4AA`) evrim hedefi |

---

## 2. Renk ve malzeme niyeti

| Güç | Mevcut ifade | Evrim yönü |
|-----|--------------|------------|
| **Cyan = teknoloji + güven** | `#22D3EE`, `#67E8F9`, electric blue glow | Hue kalibrasyon → `#00D4AA` (genom) |
| **Koyu zemin uyumu** | `#08111F` splash/login; void navy chrome | Depth Slate / Void Black ile uyumlu |
| **Metalik premium niyet** | Silver kuş gövdesi, chrome arc | Restraint ile korunur — flat stroke'a çevrilirken **kalite sinyali** kaybolmamalı |
| **Yüksek kontrast** | Beyaz/gümüş form + koyu zemin | Dark UI'da okunurluk iyi |

## 3. Geometrik korunabilir unsurlar

### 3.1 Premium kuş (`leylek-logo-premium.png`)

| Bölüm | Neden korunmalı |
|-------|-----------------|
| **Göz / accent dot** | Tek parlak nokta — "canlı sistem" + lock metaforu |
| **Gaga profili** | Leylek siluetinin en ayırt edici okuması (büyük tier'da) |
| **Boyun eğrisi** | Zarif, ileri bakan posture — operasyon yönü |
| **Kanat kontur oyuk** | Tek stroke ile F1 wing arc'a indirgenebilir |
| **Orbital arc sweep** | ~270° alt kalın üst ince — güven halkası DNA |
| **Tek ayak duruş** | Leylek ikonografisi — storytelling (F2'de literal; F1'de arc taşır) |
| **Negatif alar (arc içi)** | %30+ nefes alanı — constitution uyumu |

### 3.2 Pin SVG (`logo-leylek.svg`)

| Bölüm | Neden korunmalı |
|-------|-----------------|
| **İç kanat bezier** | En evrilebilir path — F1 wing arc kaynağı |
| **Merkez cyan dot** | Accent anchor |
| **Teardrop siluet (kısmen)** | Pin formu **terk edilir** ama dikey oran hissi korunabilir |

### 3.3 Wireframe icon (`leylektag-icon.png`)

| Bölüm | Neden korunmalı |
|-------|-----------------|
| **Horizon çizgisi** | F1 horizon line — dispatch zemin metaforu |
| **Arc / ring hint** | Lock ring öncülü |
| **Flat stroke dili** | Küçük boyutta hayatta kalma |

### 3.4 Wordmark (`feature-graphic.png`)

| Bölüm | Neden korunmalı |
|-------|-----------------|
| **"Leylek" + "TAG" hiyerarşisi** | TAG vurgulu cyan — ürün adı ayrımı |

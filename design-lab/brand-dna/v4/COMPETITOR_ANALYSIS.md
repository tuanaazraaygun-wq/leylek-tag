# LeylekTAG Competitor Analysis v4

**Version:** Brand DNA v4.0  
**Scope:** Design logic analysis only — no aesthetic copying  
**Purpose:** Neden premium hissettirdiklerini anlamak; LeylekTAG ayrışması

---

## 1. Analiz Metodu

Her rakip için:

1. **Premium hissettiren mantık** — neden işe yarıyor?
2. **Alınacak mantık** — LeylekTAG DNA'ya çeviri
3. **Alınmayacak estetik** — kopya yasağı
4. **LeylekTAG farkı** — tek cümle

**Kural:** Hiçbir tasarım kopyalanmaz. Sadece mantık analiz edilir.

---

## 2. Apple

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Restraint | Her piksel gerekçeli; boşluk lüks |
| Multimodal unity | Görsel + haptic + ses aynı olay |
| Short feedback | 200 ms içinde yanıt |
| Single character | Tüm cihazlarda tanınır dil |
| Timeless geometry | Trend'e bağımlı değil |

### LeylekTAG uygulaması

- Triad zorunluluğu Tier A
- Premium stop easing
- Boot presence 550 ms — fanfar değil
- Cross-platform same token

### Alınmaz

- iOS system sounds, SF Symbol kopyası, Apple Pay animation clone, notch/Dynamic Island UI mimic

### LeylekTAG farkı

Apple kadar sade — ama **operasyon platformu** karakterinde; consumer gadget değil.

---

## 3. Tesla

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Lock confirm | Her kritik eylem "kapanır" |
| Digital precision | UI snap keskin ama kısa |
| Technology visible | Teknoloji gösterilir; bağırmaz |
| Minimal color | Dark + single accent |
| State = feedback | Durum belirsiz kalmaz |

### LeylekTAG uygulaması

- magnetic lock metafor (QR, payment)
- lock.ringClose motion + A4 sonic
- Depth Slate + single cyan accent
- Remote ack bilateral

### Alınmaz

- Car UI layout, Tesla font, vehicle 3D render, gong startup

### LeylekTAG farkı

Tesla kadar teknolojik — ama **insan yolculuğu** merkezde; araç değil.

---

## 4. DJI

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Optical-kinetic | Işık hareket eder; sistem "görür" |
| Operational clarity | Pilot her an durumu bilir |
| Precision feedback | Scan, lock, confirm ayrı |
| Professional not toy | Ciddi araç; oyun değil |
| Calm urgency | Acil = ritim; alarm değil |

### LeylekTAG uygulaması

- scan.viewfinderFlash + scanTick
- relay.ingress offer
- Dispatch masası netliği
- Urgent offer = tighter gap not louder

### Alınmaz

- Drone iconography, RC controller UI, propeller sound, flight map aesthetic

### LeylekTAG farkı

DJI kadar operasyonel — ama **yol paylaşım** domain; hava değil.

## 5. BMW

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Material quality | Dokunsal his — digital'de = haptic |
| Brand sound | Tanınır ama nadir |
| Precision engineering | Geometrik logo, consistent spacing |
| Understated luxury | Abartısız; sessiz güven |
| Long-term identity | Decades-same core |

### LeylekTAG uygulaması

- A3 sonic anchor — BMW gong frequency değil ama same *role*
- Geometric logo master
- Haptic tier quality
- 10 yıl DNA horizon

### Alınmaz

- BMW roundel, kidney grille metaphor, driving pleasure copy, gong sound

### LeylekTAG farkı

BMW kadar kaliteli — ama **platform**; araç markası değil.

## 6. Uber

### Premium mantığı (ve eksikleri)

| Faktör | Açıklama |
|--------|----------|
| Map clarity | Pin okunur; durum net |
| Minimal pin | Tek form tanınır |
| Global consistency | Her şehir aynı |
| **Eksik** | Commodity feel; generic black |

### LeylekTAG uygulaması

- Harita okunabilirliği öncelik
- Marker aile — ama cyan meridian fark
- Durum = geri bildirim triad

### Alınmaz

- Black pin, "Uber" motion patterns, surge pricing UX panic, generic sans only

### LeylekTAG farkı

Uber netliği — **Türkiye'nin kendi platform imzası** ile.

## 7. Lyft

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Friendly differentiation | Renk ile ayrışma |
| Human touch | Pink = approachable |
| **Risk** | Too casual for ops scale |

### LeylekTAG uygulaması

- İnsanlık %10 — warm resolve; friendly pink değil
- Trust overlay — relationship not gamification

### Alınmaz

- Pink color, mustache era playfulness, casual copy tone

### LeylekTAG farkı

İnsan sıcaklığı — **operasyonel ciddiyet** korunarak.

## 8. Google Maps

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Information hierarchy | Zoom = detail level |
| Universal pin language | Instant map literacy |
| Performance | Smooth pan/zoom |
| **Eksik** | Generic; no brand journey |

### LeylekTAG uygulaması

- Zoom level marker rules
- Platform-specific marker — not red pin
- Journey line + state

### Alınmaz

- Red pin, Google color quad, Material blob markers

### LeylekTAG farkı

Maps okunabilirliği — **LeylekTAG journey dili** ile.

## 9. Waze

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Playful engagement | Community gamification |
| Real-time feel | Live map energy |
| **Risk** | Not premium; toy-like |

### LeylekTAG uygulaması

- Canlı marker breathe — gamification değil
- Real-time socket → watch haptic

### Alınmaz

- Cartoon characters, points/badges, social chat on map, ads aesthetic

### LeylekTAG farkı

Canlı harita — **sakin premium**; oyun değil.

## 10. Airbnb

### Premium mantığı

| Faktör | Açıklama |
|--------|----------|
| Trust design | Review, verify, profile |
| Warm photography | Human connection |
| Belonging narrative | Emotional brand |
| Clean booking flow | Step clarity |

# Sketch Lab Brief — Evrim, Koruma, Yasak

**Version:** Phase 2.0  
**Status:** Sketch yönergesi only

---

## 1. Evrim Haritası (mevcut → sketch)

| Mevcut öğe | Korunur? | Sketch'e evrim |
|------------|----------|----------------|
| SVG kanat path | ✅ | Wing arc — pin'den çıkarılır |
| PNG orbital arc | ✅ | Lock ring / partial orbit — 3D metal kalkar |
| Cyan nokta (SVG merkez) | ✅ | Accent dot — renk Phase 3 |
| Pin teardrop | ❌ | Retire — horizon line ile değişir |
| Tam kuş profil (PNG) | ❌ | Siluet hint veya negatif alan |
| 3D shading | ❌ | Flat stroke wireframe |
| Gradient | ❌ | Motion glow Phase 4 only |

**Tanıma testi:** Mevcut kullanıcı sketch'e baktığında *"kanat + halka ailesi"* görmeli; *"başka uygulama"* dememeli.

---

## 2. Korunacak DNA

| DNA | Sketch ifadesi |
|-----|----------------|
| Leylek hissi | Kanat arc, göç yönü, opsiyonel negatif siluet |
| Güven | Kapalı veya yarı-kapalı form; horizon zemin |
| Hareket | +2–4° ascend; ileri okuma |
| Yolculuk | Horizon / meridian çizgisi |
| Operasyon | Grid snap; precision stroke |
| Premium | Restraint; negatif alan ≥30% |
| Sadelik | ≤4 ana stroke; iç detay yok |

## 5. Sketch format

- Siyah-beyaz wireframe ASCII
- ID: S01–S25
- Aile etiketi: ARC / NEG / RING / HYBRID / RETIRE-REF (referans red)

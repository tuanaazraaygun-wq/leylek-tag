## 5. Would this identity compete internationally?

### At original master hero scale — **YES, with caveats**

| Strength | Evidence |
|----------|----------|
| Distinctive silhouette | Stork + open arc — not generic pin |
| Premium material | Chrome + cyan — instrument grade |
| Cultural ownership | *Leylek* = Turkey delivery metaphor |
| Calm trust | Anti-mascot — premium ride positioning |

| Weakness | Mitigation |
|----------|------------|
| 3D complexity | Dual ladder + mono variants |
| Not wordmark-simple | Strong app name + icon pairing in store |
| Physical media | Embroidery/laser need flat mono lockup |
| Light theme | White variant not proven |

### At B5.2 flat tier — **NO**

Fails Pentagram, Apple, and Bolt bars simultaneously.

### At LC-2 + LC-3 + 1254 hero (target) — **CONDITIONAL YES**

Can sit beside BlaBlaCar / regional premium players. **Not yet** beside Uber global wordmark simplicity until ecosystem scores ≥95.
